# Lab de GitHub · Nivelación AWS (Atos Uruguay)

Este es un sitio web **súper simple** que usamos para practicar GitHub antes del
workshop de AWS. La idea es que rompas, cambies y vuelvas para atrás sin miedo:
es una copia tuya, no le hacés mal a nadie.

## ¿Qué hay acá?

| Archivo | Qué es |
|---|---|
| `index.html` | La página. Acá está el título y la lista de nombres. |
| `styles.css` | Los estilos. Arriba de todo está el **color de acento** para cambiar. |
| `script.js` | Un poquito de JavaScript opcional. |

## Cómo lo vas a usar

1. **Forkeá** este repo (botón *Fork* arriba a la derecha) para tener tu propia copia.
2. Abrí un **Codespace** sobre tu fork (botón verde *Code* → pestaña *Codespaces* → *Create codespace*).
3. Seguí la guía del lab paso a paso.

Buscá los comentarios con 👇 dentro de los archivos: te marcan qué es fácil de cambiar.

> Esto es un warm-up de GitHub, no el workshop de AWS. El miércoles ese mismo
> "push" que vas a aprender acá va a disparar un pipeline que buildea y deploya
> en AWS. Es el mismo gesto, con más cosas atrás.
